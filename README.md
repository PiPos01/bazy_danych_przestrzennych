# 🌍 PostGIS & FME - Rozwiązania i Zadania Przestrzenne

To repozytorium zawiera zbiór zadań, skryptów SQL oraz projektów ETL (Extract, Transform, Load) wykonanych przy użyciu **PostGIS** oraz **FME (Safe Software)**. Celem projektu jest demonstracja umiejętności przetwarzania, analizy i automatyzacji danych przestrzennych.

---

## 🚀 Technologie
* **PostgreSQL / PostGIS** – Przestrzenna baza danych.
* **FME Form (wcześniej FME Desktop)** – Platforma do integracji danych.
* **QGIS** – Wizualizacja i weryfikacja wyników.
* **SQL** – Zaawansowane zapytania i optymalizacja.
