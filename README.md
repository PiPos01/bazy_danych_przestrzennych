# 🌍 PostGIS & FME - Spatial Solutions and Tasks

This repository contains a collection of tasks, SQL scripts, and ETL (Extract, Transform, Load) projects created using **PostGIS** and **FME (Safe Software)**. The goal of this project is to demonstrate skills in spatial data processing, analysis, and automation.

---

## Technologies
* **PostgreSQL / PostGIS** – Spatial database.
* **FME Form (formerly FME Desktop)** – Data integration platform.
* **QGIS** – Visualization and result verification.
* **SQL** – Advanced queries and database optimization.

## Task Scope - PostGIS
This section includes solutions to problems related to vector and raster analysis:
1.  **Proximity Analysis and Buffering** – Determining areas of influence around objects.
2.  **Spatial Relationships** – Spatial Joins and topology testing.
3.  **Optimization** – Creating spatial indexes (GiST) and data clustering.
4.  **OSM Data Processing** – Working with OpenStreetMap data (hstore, tags).
5.  **Geometry vs. Geography** – Calculations on a spheroid vs. a Cartesian plane.

---

## Task Scope - FME
GIS process automation projects:
1.  **Format Conversion (ETL)** – Data migration from CAD/Excel files to the PostGIS database.
2.  **Data Validation (Data Quality)** – Automatic detection of topological errors.
3.  **Web Scraping & API** – Fetching data from external APIs (e.g., weather or transit) and saving it to the database.
4.  **Automated Reporting** – Generating PDF/Excel reports based on spatial analyses.
5.  **Coordinate System Transformation** – Bulk reprojection of data between different coordinate systems.
